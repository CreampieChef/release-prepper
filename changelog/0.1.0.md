# First public Windows release

This version of Release Prepper is optimized for making single-video SiteRip
releases.

## Features

* Automatic scene data import from StashDB
* Automatic screenshot and screenlist generation
* Automatic torrent generation (private only in this version)
* Automatic image uploads to 4 supported hosters:
    * FastPic
    * TurboImageHost
    * Pixhost
    * Postimages
* Automatic release description generation
* Automatic upload of a release draft to PornoLab
* Clone release. Copies all text fields and the uploaded poster to a new
  release. Useful for releasing the same scene in a different resolution.
* Support for Russian and English user interface languages

## Beta features

Beta features are subject to change in future releases.

* Support for video pack releases
* Support for photoset releases
* Support for photoset pack releases
* Recent releases browser

## Installation

Simply unzip the archive and run `release_prepper.exe`.
