# Version 0.2.0

## New features

* The Linux build is now available.
* You can create non-private torrents. Set the default for the Private flag in
  Settings.
* Single photoset and photoset pack are no longer marked as beta, and their
  templates have been revised to match the tracker's template style.
* You can post a finished release straight to the tracker. Review the draft
  before posting: the post cannot be taken back.
* You can import scene data from StashDB when creating a single photoset
  release, which is useful when uploading a scene photoset.
* You can sort the tags alphabetically and remove duplicate tags.
* You can see a scan and a pick as they work: the progress row shows how far the
  run has reached, and each set, video and picked photo appears in the UI as it
  is read or copied.
* You can scroll the page in the tab you are on with Home, End, Page Up and
  Page Down.
* The app adds a short "Made with Release Prepper" line at the end of the post,
  so other users can find the app. You can remove it for a release, or turn it
  off by default in Settings.

## Fixes

* The app remembers its window size and its maximized state between runs. On Windows the window is opened
  centred on the primary monitor.
* The app no longer hangs when opening a large video or photo pack, and shows
  the progress as it reads the files instead.
* The recent releases browser no longer shows entries whose folder or
  index file is gone.

## Features still in beta

Beta features are subject to change in future releases.

* Video pack release
* Recent releases browser
* Image folder upload

## Known issues

* **Important!** Do not switch away from a tab while the app is running a long
  operation such as an upload: it may lose track of the results. This will be
  fixed in the next update.

## Installation

### Windows

Unzip the archive and run `release_prepper.exe`.

**System requirements**: Windows 10/11 64-bit

### Linux

Download the AppImage, make it executable, and run it.

**System requirements**:

* x64 system
* ffmpeg and mtn from the distribution packages:
  [ffmpeg](https://ffmpeg.org/download.html#build-linux),
  [mtn](https://gitlab.com/movie_thumbnailer/mtn/-/wikis/home#installation)
* glibc 2.38 or higher
* fontconfig, for the glyphs the app draws
* GTK. App uses the host's GTK, which any desktop install has
* A running XDG desktop portal, since the folder picker is the portal's dialog
  over D-Bus: a system without a portal backend cannot pick a folder
* A D-Bus session, and a compositor
* shared-mime-info (optional, highly recommended): with no system MIME database
  the tool guesses the type from the extension, so the `Content-Type` sent when
  uploading an image is wrong
* A Secret Service reachable over D-Bus (optional, highly recommended). The
  plaintext credential storage fallback works without it, but it is untested and
  not recommended

Before you start, open Main Menu → System Check. It reports whether `ffmpeg`,
`ffprobe` and `mtn` are available, and on Linux whether the credential store can
be reached.
